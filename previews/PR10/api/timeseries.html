Fetch timeseries data for one or more feeds ​

GET /timeseries/data

Fetch timeseries data for one or more feeds​

GET
/timeseries/data

Returns timeseries data for a given system. Response is a JSON object keyed by feed name; each value is an array of [timestamp_ms, value] pairs (timestamp is unix epoch in milliseconds; value is a number, possibly null).

Requesting a feed name that does not exist on the system causes the upstream PHP backend to inline a warning into the response body (HTTP 200 but invalid JSON). Always call /timeseries/available first to discover valid feed names.
