HeatpumpMonitorAPI.HeatpumpMonitorAPIAPI.timeseries_data Method

Fetch timeseries data for one or more feeds

Returns timeseries data for a given system. Response is a JSON object keyed by feed name; each value is an array of [timestamp_ms, value] pairs (timestamp is unix epoch in milliseconds; value is a number, possibly null). Requesting a feed name that does not exist on the system causes the upstream PHP backend to inline a warning into the response body (HTTP 200 but invalid JSON). Always call /timeseries/available first to discover valid feed names.

Params:

  • id::Int64 (required)

  • feeds::String (required)

  • start::Int64

  • end::Int64

  • interval::Int64

  • average::Int64

  • delta::Int64

  • timeformat::String

Return: Dict{String, Vector{Vector{Any}}}, OpenAPI.Clients.ApiResponse
