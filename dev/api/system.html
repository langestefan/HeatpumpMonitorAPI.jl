Get metadata for a single system ​

GET /system/get.json

Get metadata for a single system​

GET
/system/get.json

Returns meta data for the selected system. The shape is a subset of /system/list/public.json — the following fields are present only in /list and absent here: heatpump_elec_feedid, heatpump_heat_feedid, heatpump_elec_ago, heatpump_heat_ago, heatpump_max_age, heatpump_model_id, heatpump_url, manufacturer_id, photo_count.

Query Parameters

Type
integer
Required
Minimum
1

List the logged-in user's systems ​

GET /system/list/user.json

List the logged-in user's systems​

GET
/system/list/user.json

When logged in this returns the system list for the logged-in user. Requires an authenticated session cookie established via the web UI at /user/login.

Authorizations​

sessionCookie

Session cookie established by logging in via the web UI at /user/login. Required only for /system/list/user.json. Cookie name is implementation-specific to the upstream PHP application; verify against your captured Set-Cookie header.

Type
API Key (cookie: PHPSESSID)

Type
string
Format
"date"
end

Window end date (inclusive), format YYYY-MM-DD.

Type
